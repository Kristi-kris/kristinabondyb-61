# Лабораторная работа 1. Первые программы

Вариант 5: спортивного магазина (мячи и скакалки). Запускать из корня проекта, например `python lab01/profile.py`.

## Файлы

- `hello.py` — вывод двух строк из задания подготовки.
- `profile.py` — карточка студента.
- `workload.py` — расчёт недельной учебной нагрузки.
- `debug.py` — три исправленных фрагмента с объяснимыми подписями и типами.
- `swap.py` — обмен аудиторий через временную переменную.
- `variant.py` — расчёт заказа из двух позиций.

## Проверки

| Программа | Ввод | Ожидаемый и фактический результат |
|---|---|---|
| profile | возраст 17, подготовка 10.5 ч/нед. | возраст через 4 года 21; 42.00 ч за 4 недели; 1.50 ч в день. Совпало. |
| profile | возраст 20, подготовка 0 ч/нед. | возраст через 4 года 24; оба расчёта времени 0.00 ч. Совпало. |
| workload | 3 занятия по 90 мин, 2 по 45 мин, доступно 10 ч | 270 и 90 мин; итого 360 мин / 6.00 ч; свободно 4.00 ч; за 4 недели 24.00 ч. Совпало. |
| workload | по обоим предметам 0 занятий | общая нагрузка 0 мин, свободное время равно доступному. Совпало. |
| debug | возраст 17 | фрагменты: 5, 18 и 7.0; типы строк преобразуются в int. Совпало. |
| swap | А-101 и Б-202 | после обмена: Б-202 и А-101. Совпало. |
| variant | 3 мяча по 12.50, 2 скакалки по 20.00, доставка 10.00, оплата 100.00 | 37.50 и 40.00; товары 77.50; итого 87.50; 5 единиц; сдача 12.50. Совпало. |

Все программы проверены запуском на Python 3.14.6. Денежные поля форматируются до двух знаков; значения варианта вводятся последовательно.
