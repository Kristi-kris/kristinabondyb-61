# Лабораторная работа 4. Циклы

Вариант 5: подсчитать положительные числа и их сумму. Запуск: `python lab04/range_numbers.py` (аналогично для остальных файлов).

## Проверки

| Программа | Ввод | Ожидаемый и фактический результат |
|---|---|---|
| range_numbers | 2, 4 | 2, 3, 4 по одному на строке. Совпало. |
| range_numbers | 4, 2 | 4, 3, 2 по одному на строке. Совпало. |
| range_numbers | 3, 3 | одно число 3. Совпало. |
| statistics | n=3; -5, -2, -8 | сумма -15, положительных 0, максимум -2. Совпало. |
| statistics | n=1; 0 | сумма 0, положительных 0, максимум 0. Совпало. |
| positive_input | 0, -2, 3 | квадрат 9, отклонено 2 попытки. Совпало. |
| variant | n=7; -12, -3, 0, 2, 10, 15, 20 | чётных 5, сумма 20. Совпало с контрольным набором варианта 5. |
| variant | n=0 | чётных 0, сумма 0. Совпало. |
| variant | n=2; -3, 15 | чётных 0, сумма 0. Совпало. |

Для цикла суммирования чисел от 1 до 4:

| Итерация | Сумма до | Добавлено | Сумма после |
|---:|---:|---:|---:|
| 1 | 0 | 1 | 1 |
| 2 | 1 | 2 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 6 | 4 | 10 |

Диапазон реализован с включённой конечной границей: для убывания шаг `-1`, а правая граница `range` сдвигается на единицу вниз. Статистика обрабатывает поток ввода сразу, не сохраняя числа в списке.
