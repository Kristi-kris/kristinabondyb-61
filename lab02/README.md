# Лабораторная работа 2. Вычисления

Вариант 5: количество участников и количество участников в команде. Запуск: `python lab02/time_parts.py` (аналогично для остальных файлов).

## Прогноз выражений

| Выражение | Прогноз | Python |
|---|---:|---:|
| `2 + 3 * 4` | 14 | 14 |
| `(2 + 3) * 4` | 20 | 20 |
| `17 // 5` | 3 | 3 |
| `17 % 5` | 2 | 2 |
| `-7 // 2` | -4 | -4 |

Целочисленное деление округляет вниз, поэтому для отрицательного числа `-7 // 2` равно `-4`.

## Проверки

| Программа | Ввод | Ожидаемый и фактический результат |
|---|---|---|
| time_parts | 0 | 0 ч 0 мин 0 с. Совпало. |
| time_parts | 59 | 0 ч 0 мин 59 с. Совпало. |
| time_parts | 60 | 0 ч 1 мин 0 с. Совпало. |
| time_parts | 3671 | 1 ч 1 мин 11 с. Совпало. |
| purchase | цена 45, количество 3, оплачено 200 | стоимость 135 руб., сдача 65 руб. Совпало. |
| purchase | цена 45, количество 0, оплачено 100 | стоимость 0 руб., сдача 100 руб. Совпало. |
| variant | 0 участников, 10 количество участников в команде | команд 0, остаток 0, требуется 0. Совпало. |
| variant | 20 участников, 10 количество участников в команде | команд 2, остаток 0, требуется 2. Совпало. |
| variant | 21 участников, 10 количество участников в команде | команд 2, остаток 1, требуется 3. Совпало. |

Для варианта нужны неотрицательный объём и положительная вместимость. Программы используют целочисленные операции, циклов и условий в `variant.py` нет.
